# Portofolio Olivia Tambunan

Halaman web portofolio satu halaman untuk memperkenalkan profil, proyek, dan layanan konsultasi. Dibuat dengan HTML5 semantik dan CSS3 murni (tanpa framework), sebagai tugas mandiri matakuliah Pemrograman dan Pengujian Aplikasi Web di Institut Teknologi Del.

## Fitur

- **Tentang saya**: pengantar singkat dan kartu profil berisi fokus serta keahlian.
- **Portofolio**: tiga proyek dalam bentuk kartu (_Lost & Found Asrama_, _Immunization App_, _JExpress_) dan tabel rekapitulasi proyek.
- **Formulir layanan**: formulir konsultasi dengan pengelompokan `fieldset`, label eksplisit, dan validasi bawaan HTML5.
- **Responsif**: tata letak menyesuaikan layar desktop hingga ponsel dengan CSS Grid, Flexbox, dan media query.

## Teknologi

- HTML5 (elemen semantik: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
- CSS3 (Custom Properties, Grid, Flexbox, Media Queries)
- Google Fonts: Playfair Display dan Plus Jakarta Sans
- Git dan GitHub Pages
